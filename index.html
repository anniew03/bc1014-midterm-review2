What is a method?

  • A method is a sequence of statements that has a name, may have paramter values, and may return a value.
  • Methods return at most one value.
  • The return value of a method is returned to a calling method
  • When you call a method, give exactly as many arguments as the method has parameters.

    • Example

    larger takes two ints and returns the bigger one. main is the calling method. Run it, then try the Trace button.

    • larger is the name of the method.
    • int a, int b are the parameter variables. They hold the inputs.
    • The int before the name is the return type. Every value this method returns must be an int.
    • In larger(7, 3), the values 7 and 3 are the arguments. The first argument goes into a and the second into b.
    • The return value takes the place of the call. After larger(7, 3) returns 7, the line int x = larger(7, 3); behaves like int x = 7;.

    How to Implement a Method

    1. Pick a name for the method
    2. Declare a variable for each method (aka paramter variables)
    3. Specify the type of the return value
    4. Add the public static modifiers
    5. Write the method body, include return statement(s)

    Parameter Passing

    • When a method is called with arguments, each parameter value is initialized with the corresponding argument
    • An argument can be a value, a variable, or an expression such as x + 1.
    • Parameter variables only exist inside the method. They are created when the method is called and disappear when it returns. Code in another method cannot use them.
    • The same goes for any variable you declare inside a method.
    • In Java, a method can never change the contents of a variable that was passed as an argument. The parameter variable holds a copy of the value.

    Returning from a Method

    • A return statement can return a variable or an expression, such as return n;, return -n;, or return a + b;.
    • Upon executing a return statement, the code will exit the method immediately. Anything after will not be processed.
    • A return statement can also return nothing and is used when you want to retun early from a void function

    Recursion

    • A recursive method is a method that calls itself.
    • Every recursive method needs a base case that stops the recursion.
    • A recursive call should solve a smaller version of the original problem.
    • Each recursive call has its own parameter variables and local variables.

    Answer

    Think about what happens when we remove the last digit of a number:

    • 583 / 10 is 58 using integer division.
    • 58 has one fewer digit than 583.
    • Every positive one-digit number has exactly one digit.

    We can use these observations to write a recursive method:

    How it works:

    1. Base case: If n < 10, the number has one digit, so return 1.
    2. Recursive case: Otherwise, divide n by 10 to remove its last digit, count the digits in the smaller number, and add 1 for the digit we removed.

    For example, countDigits(583) works like this:

    countDigits(583)
      = 1 + countDigits(58)
      = 1 + 1 + countDigits(5)
      = 1 + 1 + 1
      = 3

    Notice that each recursive call receives a smaller number. Eventually, the method reaches the base case and the calls return their results.
